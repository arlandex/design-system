Nataliya's style guide

This style guide supports both diagram illustrations and structurally similar, information-architecture-led HTML pages. The warm-neutral colourway is the default across the system. The Mineral colourway is a contextual alternative reserved for specific information-architecture pages; it does not replace the default.

Both palettes contain six aligned system colours, including their own Body Ink reading tone in the fifth position. Body Ink is a functional neutral, not an accent. The Mineral colourway is used only where that information-architecture treatment is intentional.

Accents

Approved accent uses

Use the active colourway's Ink token for accents. The five treatments below are the currently approved uses, not a limit on future patterns. Any new use should serve the same focal or signalling purpose, remain the boldest element in view and never become a page background.
